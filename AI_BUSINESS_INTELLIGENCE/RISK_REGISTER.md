## 2. Non-Negotiable Pre-Launch Gate Checklist

Before running paid acquisition, publishing to mobile app stores, or hosting public user stories:
1. **Zero XSS sinks** in story/JSON/script import (`R2`).
2. **100% IP-clean default characters, scripts, and skin branding** (`R1`).
3. **Deduplicated asset storage** so multi-episode creators don't corrupt/bloat IndexedDB (`R5`).
4. **Reliable 1-click MP4/WebM export** working on both desktop and mobile (`R6`).
5. **Automated UGC safety filter + DMCA takedown flow** before enabling public share links (`R7`).
